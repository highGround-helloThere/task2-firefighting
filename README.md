# Task 2 Firefighting Robot

VR and Edge AI based intelligent robot teleoperation and autonomous firefighting project.

## Modules

- `unity/` - Unity and VR client
- `robot/` - TonyPi control
- `edge_ai/` - Orange Pi perception
- `autonomy/` - navigation, obstacle avoidance, and control arbitration
- `config/` - shared configuration

## Team workflow

Create a feature branch for each module and open a pull request before merging into `main`.
